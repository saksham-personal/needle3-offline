# Needle 3 Offline Runtime

Offline deployment package containing the full Needle 3 model
and the Windows AMD64 Needle 3 inference engine.

## Model

Full Needle 3.

No reduced ladder depth is used.

## Download

Artifacts are distributed using GitHub Releases rather than
being committed directly into Git history.

Current release:

**needle3-full-win-amd64**
